# UgyenPee ECCD Public Website
## Design System & UI Direction

**Version:** 1.0  
**Status:** Draft

---

## 1. Design Goal

The UgyenPee ECCD website should feel:

- Warm
- Safe
- Caring
- Natural
- Playful
- Professional
- Trustworthy
- Bhutanese
- Modern

Avoid making it look like either:
- a corporate consulting website, or
- an overly cartoonish children's game website.

The ideal visual balance is:

> **Modern editorial website + warm early-childhood environment.**

---

## 3. Typography

Recommended direction:

### Display Font
A warm, rounded or humanist display typeface.

Possible options:
- Fraunces
- DM Serif Display
- Playfair Display

### Body Font
A highly readable sans-serif:

- Inter
- Manrope
- DM Sans
- Nunito Sans

### Principle

Use typography to create warmth without sacrificing professionalism.

---

## 4. Typography Scale

```text
Display XL    64px / 1.05
Display L     52px / 1.10
Heading 1     40px / 1.15
Heading 2     32px / 1.20
Heading 3     24px / 1.25
Body L        20px / 1.60
Body          16px / 1.60
Body S        14px / 1.50
Caption       12px / 1.40
```

Mobile sizes should scale down appropriately.

---

## 5. Layout

Use generous whitespace.

### Desktop

Maximum content width:
`1200–1280px`

Standard horizontal padding:
`32–64px`

### Mobile

Horizontal padding:
`20–24px`

---

## 6. Border Radius

Use soft rounded corners.

Suggested:
- Cards: 20–24px
- Buttons: 999px or 12–16px
- Images: 20–28px
- Inputs: 12–14px

Avoid excessive rounding on every element.

---

## 7. Photography Direction

Photography is one of the most important design elements.

Prefer:

- Real children
- Real facilitators
- Real classrooms
- Real outdoor areas
- Real activities
- Natural expressions
- Candid moments
- Bhutanese environment
- Warm natural lighting

Avoid excessive stock photography.

### Image style

Natural + documentary + warm + authentic.

## 9. Component System

### Buttons

Primary:
- Forest background
- White text
- Rounded
- Medium/large size

Secondary:
- Transparent or cream
- Forest border/text

Text button:
- Minimal
- Arrow icon

---

### Cards

Use cards for:
- Programmes
- Development areas
- Facilities
- Parent resources
- News

Cards should have:
- image/icon
- heading
- short description
- optional CTA

Avoid dense card grids.

## 15. Motion

Animation should be gentle.

Good:
- Fade-in
- Slight upward reveal
- Image reveal
- Soft hover movement
- Scroll-based storytelling

Avoid:
- Constant bouncing
- Excessive parallax
- Loud transitions
- Long loading animations

Respect:

`prefers-reduced-motion`

---

## 16. Accessibility

Required:
- WCAG-conscious colour contrast
- Keyboard navigation
- Focus states
- Semantic headings
- Accessible buttons
- Descriptive alt text
- Reduced-motion support
- Large enough touch targets
- No text embedded only in images

---

## 17. Responsive Behaviour

### Mobile

Prioritise:
1. Hero
2. About
3. Programme
4. Admissions
5. Gallery
6. Contact

Navigation becomes a drawer.

### Tablet

Use two-column layouts where appropriate.

### Desktop

Use:
- large editorial sections
- photography
- asymmetric layouts
- generous whitespace
